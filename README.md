# UrbanFlow

Projekt der Gruppe 02 für die Module M241 und M245. Mit UrbanFlow vergleichen Lernende zwei Verkehrsnetze. Sie prüfen, wie eine neue Verbindung die Reisezeiten, die erreichbaren Ziele und die Kosten verändert.
